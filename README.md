# Les 21 Défis
Site HTML léger + API Node (sans dépendance). Voir `deploy.md`.
- Pages publiques : accueil, vision (message à la nation), programme (chemin), actualités, députés, histoire, adhésion, contact.
- Espace membre (`espace.html`) : carte, grade, 21 défis (privés, servis par l'API), abonnements aux députés.
- Admin (`admin.html`, code `ADMIN_TOKEN`) : valider membres, grades, candidatures, articles.
- Images : remplacer `public/images/peuple.svg|enfants.svg|paix.svg` par vos photos (mêmes noms de fichier dans index.html à adapter).
- Contenu privé des défis : `private/defis.json` (jamais servi en fichier).
